# XCode

XCode は、プラットフォームのアカウントプール、API Key、サブスクリプション、残高課金、利用記録を管理するセルフホスト型 AI API ゲートウェイです。現在のランタイム実装には Sub2API アダプターを使用します。

詳細は [English README](README.md)、[中文 README](README_CN.md)、[アーキテクチャ](docs/ARCHITECTURE.md) を参照してください。

リリースの契約は `xcode:latest` イメージと `xcode_latest.tar` オフラインパッケージです。GitHub Actions は GHCR へ公開しません。
