# XCode 项目定义

## 立项

XCode 是一个面向个人和小型团队的 AI API 网关与订阅分发平台。它把用户、API Key、平台账号、套餐、余额、计费和使用记录统一管理，并通过可替换的运行时适配器连接上游 AI 服务。

## 产品目标

- 用一个管理后台维护多个平台及其账号池。
- 通过 API Key 授权平台、多个套餐和余额，按规则选择可用资产。
- 以套餐优先、余额回退的顺序完成可靠扣费，并留下可审计的使用记录。
- 支持 OpenAI Images、Chat Completions、Responses 和 Messages 等当前生产路径。
- 以离线 Docker 包交付，适合没有外网构建环境的服务器。

## 核心用户

- 管理员：维护平台、账号、模型白名单、套餐、倍率、支付和运维配置。
- API 使用者：使用 API Key 调用已授权的平台和端点，查看余额、订阅和用量。
- 运维人员：加载离线镜像，升级应用容器并保留 PostgreSQL、Redis 数据卷。

## 功能范围

### 当前范围

- 平台与模型白名单、统一端点能力、平台账号池。
- API Key 的多平台、多套餐和余额授权。
- 套餐时长、额度、每日/每周/每月限制和独立倍率。
- 全局余额倍率、用量记录、Token/费用/延迟/输出速率/缓存率展示。
- OAuth 刷新、账号调度、失败切换、协议适配和上游错误透传。
- 支付、充值、CDK 兑换和独立订阅发放。

### 明确非目标

- 不把 XCode 变成通用的账号托管或上游服务商。
- 不在当前阶段扩展 Grok、Gemini、Anthropic 其他入口或 Live/WebSocket。
- 不恢复旧 Group、BillingProfile、`group_id`、`group_ids` 或账号级模型映射作为新架构入口。
- 不为仓库改名而重命名内部二进制、数据库表或 API 路径。

## 成功标准

一次请求能够根据 Key 授权、平台能力、端点和有效订阅选出唯一可用平台与账号；请求成功后，使用记录、实际平台、倍率、Token、费用和扣费来源保持一致；应用升级只替换应用容器，不重建数据卷。
