# 运行时适配器边界验证与发布门禁

- 状态：已确认
- 日期：2026-08-11
- 结论：Sub2API 继续作为当前唯一运行时内核；ProductCore、ApplicationGateway、GatewayRuntime、Pricing 和 Usage 通过稳定契约隔离，后续替换内核时只替换适配器实现。
- 验证：Go `internal/...` 全量单元测试通过；`migrations`、`cmd/...` 测试通过；`cmd/server` 构建通过；前端 Vitest 199 个文件/1348 个用例、typecheck、lint 和 production build 全部通过。
- 兼容边界：现有协议、OAuth、账号调度、流式、重试和失败切换算法保持不变。Gin HTTP carrier 只存在于 Sub2API Adapter 内部；无模型的 Live sideband、WebSocket 和视频状态控制路径保留专用状态机，不通过需要模型决策的产品入口硬套。
- 发布门禁：完成远程递增 Tag、GitHub 离线镜像和服务器备份后，才允许替换应用容器；不得修改 PostgreSQL、Redis、证书或域名。服务器验收必须分别核对成功扣费、失败不扣费、平台/账号归因和套餐优先级。
- 相关文件：`backend/internal/gatewayruntime/`、`backend/internal/applicationgateway/`、`backend/internal/handler/sub2api_*`、`backend/internal/service/sub2api_*`、`docs/superpowers/plans/2026-08-10-runtime-adapter-boundary.md`。
