# XCode 独立仓库迁移交接

- 状态：已确认
- 日期：2026-08-20
- 结论：XCode 使用独立的 `xiaohuihuitop/xcode` 仓库和 `main` 生产分支；官方 Sub2API 只作为 `upstream` 同步来源和当前 Runtime 实现。
- 原因：产品层已与官方项目分化，独立仓库能避免旧 Fork 历史、旧发布线和产品文档混淆后续开发。
- 影响：后续发布从 `v1.0.0` 开始，GitHub Actions 只生成 `xcode_latest.tar`；同步官方必须经过适配器边界审查。
- 相关文件：`README.md`、`docs/PROJECT_DEFINITION.md`、`docs/ARCHITECTURE.md`、`docs/DEVELOPMENT_GUIDE.md`、`docs/HANDOFF.md`。
