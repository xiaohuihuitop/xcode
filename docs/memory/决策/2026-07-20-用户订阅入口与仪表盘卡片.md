# 用户订阅入口与仪表盘卡片

- 状态：已确认
- 日期：2026-07-20
- 结论：用户侧边栏永久隐藏“我的订阅”；用户仪表盘集中显示有效订阅摘要卡片。
- 原因：订阅状态应在用户登录后的主视图直接可见，侧边栏不保留重复入口。
- 影响：保留 `/subscriptions` 直链和 `/admin/subscriptions` 管理端入口；不删除订阅 API、路由或订阅管理功能。
- 展示：最多显示四个有效订阅；卡片包含分组名称、到期时间、当前生效额度窗口、已用金额、额度、余量和进度。无额度套餐显示“不限额”。
- 容错：获取有效订阅失败时显示空卡片列表，不能阻断仪表盘统计、图表或使用记录加载。
- 相关文件：
  - `frontend/src/components/layout/AppSidebar.vue`
  - `frontend/src/views/user/DashboardView.vue`
  - `frontend/src/components/user/dashboard/UserDashboardStats.vue`
  - `frontend/src/components/user/dashboard/UserSubscriptionSummaryCard.vue`
- 验证：运行订阅卡、仪表盘和侧边栏定向 Vitest；运行 `npm run typecheck`、`npm run lint:check`、`npm run build`。
