# 计费候选保留原始订阅窗口

- 状态：已确认
- 日期：2026-08-24
- 结论：计费候选列表必须保留数据库中的窗口起始时间和用量，不得复用面向展示的过期窗口归一化结果。
- 原因：展示归一化会将过期窗口起始时间置空，导致计费预检查丢失维护信号；后续缓存资格检查仍读取旧日超额用量，从而错误返回 `daily usage limit exceeded`，并阻断多订阅候选切换。
- 影响：`ListActiveSubscriptions` 直接读取并克隆活动订阅数据库快照；展示接口继续使用原有归一化语义。跨日窗口由 `ValidateAndCheckLimits`、`EnsureWindowMaintenance`、条件重置和缓存失效链推进；同日已超额订阅仍跳到下一候选，一日卡仍不重复获得日额度。
