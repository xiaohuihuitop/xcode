# XCode 仅发布离线包

- 状态：已确认
- 日期：2026-08-20

## 结论

XCode 不发布到 GHCR。GitHub Actions 的 XCode 发布工作流只负责质量门禁、构建 Linux amd64 本地镜像 `xcode:latest`、生成 `xcode_latest.tar` 及 SHA256 校验文件，并将它们上传到 GitHub Release。

## 约束

- 新仓库 `xiaohuihuitop/xcode` 的 `v*` Tag 触发 XCode 发布工作流。
- 离线服务器使用 `docker load -i xcode_latest.tar`，加载后镜像名为 `xcode:latest`。
- 不配置 GHCR 登录、Token 或镜像推送；旧的通用 `release.yml` 不再响应 Tag 自动触发，仅保留手动入口。
- 内部 `/app/sub2api` 二进制名、数据库表和现有部署数据不因交付命名改变。
