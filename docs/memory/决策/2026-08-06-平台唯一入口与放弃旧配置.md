# 平台唯一入口与放弃旧配置

- 状态：已确认
- 日期：2026-08-06
- 结论：平台是唯一业务路由概念，`platform_id` 是账号唯一可配置的平台归属；My2 后续实现不兼容、不迁移也不回退到旧平台、账号分组和平台授权配置。
- 原因：旧 `platform`、平台账号池和分组同时暴露造成概念重复，并迫使创建、调度和授权维持多套来源。测试环境的旧路由配置可以放弃，因此没有必要继续承担双读和兼容复杂度。
- 影响：升级前备份并重建平台、模型规则、账号和 API Key 平台授权；保留用户、API Key 本体、余额、套餐、订阅实例、支付审计和历史使用记录。API Key 需要重新勾选平台。
- 相关文件：`docs/superpowers/specs/2026-08-06-platform-pool-account-adapter-design.md`、`backend/ent/schema/platform.go`、`backend/ent/schema/account.go`、`frontend/src/components/account/CreateAccountModal.vue`

## 长期约束

- 平台保存协议适配器、模型规则、端点能力和账号集合；账号没有第二个可配置的平台来源。
- 现有 `accounts.platform` 可以作为服务端派生的 GatewayRuntime 适配器快照保留，但客户端不可编辑；平台已有账号后不可修改适配器。
- 平台解析必须先取得模型候选，再按 API Key 授权和端点能力过滤；同一模型可以由不同平台分别承载 Chat 与 Responses。
- 模型基础价格和自定义价格独立于 Group，资产倍率只取套餐实例快照或全局余额倍率。
- 旧 `groups`、`group_id` / `group_ids`、`account_groups` 和旧平台授权不再参与新请求，不提供兼容 API 或运行时回退。
- 配置重建不能删除或重算用户财产、支付审计和历史用量；被历史数据引用的旧行只读归档，物理删除另立迁移。
