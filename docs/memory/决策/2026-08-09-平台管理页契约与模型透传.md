# 平台管理页契约与模型透传

- 状态：已确认
- 日期：2026-08-09
- 结论：平台管理页按平台级端点能力渲染；模型白名单透传规则的 `upstream_model` 必须为空，只有显式映射才填写上游模型名。
- 原因：端点能力已从模型规则收口到 Platform；通配符白名单若把自身模式写入 `upstream_model`，运行时会将 `glm*`、`gpt-*` 等模式作为字面模型发送给上游。
- 影响：平台列表、平台编辑器、模型规则转换、平台服务校验和相关回归测试；编辑平台时保留已有禁用规则，不静默删除。
- 相关文件：`frontend/src/views/admin/PlatformsView.vue`、`frontend/src/components/admin/platform/PlatformPoolDialog.vue`、`frontend/src/components/admin/platform/platformModelRules.ts`、`backend/internal/service/platform_service.go`
- 验证方式：平台页面契约测试、模型规则转换测试、平台 handler/service/repository 回归、前端 Vitest/typecheck/lint/build。
