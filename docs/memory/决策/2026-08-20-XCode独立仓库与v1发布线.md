# XCode 独立仓库与 v1 发布线

- 状态：已确认
- 日期：2026-08-20
- 结论：从当前已验证的 `my2.0` 基线建立独立产品仓库 `xiaohuihuitop/xcode`，使用 `main` 作为生产分支，Tag 从 `v1.0.0` 开始。
- 原因：现有仓库是官方项目 Fork，默认 `main` 不是生产代码；独立仓库能明确产品边界，同时保留完整历史和官方 `upstream` 按需同步能力。
- 影响：GitHub Actions 使用 `v*` Tag 且校验 `origin/main`；只构建本地 `xcode:latest` 并上传 `xcode_latest.tar`，不发布 GHCR。旧 `sub2api` 仓库和 `my2-v0.2.x` Release 仅作为历史来源，不再作为 XCode 新版本线。
- 兼容边界：本次不改内部 `/app/sub2api` 二进制、数据库表、服务标签、API 路径、schema 或现有服务器数据；官方源继续配置为 `upstream`。
