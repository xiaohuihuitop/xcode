# 订阅与计费领域拆分

> 2026-08-06 修订：本决策中的平台与资产解耦、套餐实例快照和余额回退原则继续有效；
> `group_id` / `group_ids` 路由兼容已由[平台唯一入口与放弃旧配置](2026-08-06-平台唯一入口与放弃旧配置.md)替代，不得用于新请求。

- 状态：已确认
- 日期：2026-08-03
- 结论：账号分组只负责账号与路由；余额价格规则、订阅套餐模板和用户订阅实例拆分为独立模型。
- 原因：现有 `Group` 同时承载账号池、余额倍率和订阅额度，导致套餐与余额配置重复，并限制同一用户同分组多条订阅。
- 影响：
  - 新增独立的余额计费规则和订阅套餐模板；套餐实例保存额度、时长和倍率快照。
  - 订阅倍率覆盖余额倍率；余额不再支持用户专属倍率。
  - 同分组多订阅按最早到期、再创建时间消耗；套餐都不可用后回退余额。
  - 历史实现曾保留 API Key 的 `group_id` / `group_ids` 路由；该部分已于 2026-08-06 废止。RPM override 是否保留不影响平台和资产选择。
