# My2 隔离预发布通道

- 状态：已确认
- 日期：2026-08-04
- 结论：`my2.0` 的不稳定重构通过独立 `my2-v<版本>` Tag 发布测试 Docker，不得使用或覆盖正式 `latest`。
- 原因：用户需要在服务器上测试订阅与计费重构，同时保持 `my` 正式镜像可回退且不受影响。
- 影响：新增独立 GitHub Actions 工作流、GHCR `my2-*` 标签和 `sub2api_my2_latest.tar`；不改正式 `release.yml`，不回写 `main` 的 `VERSION`。
- 相关文件：`.github/workflows/my2-release.yml`、`docs/superpowers/specs/2026-08-04-my2-预发布-docker-通道-design.md`、`docs/memory/当前状态.md`
