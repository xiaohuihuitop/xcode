# 生产验收默认模型

- 状态：已确认
- 日期：2026-08-21
- 结论：后续生产验收默认使用 `gpt-5.6-sol`，并在有效 GLM 上游账号准备好后执行 `glm-5.2` 的真实网关与计费验收。
- 原因：用户明确指定这两个模型为后续测试目标；当前 `gpt-5.6-sol` 已通过 Chat、Responses、SSE 和套餐扣费验收，`glm-5.2` 尚不具备可验证的上游条件。
- 影响：测试不得以仅有 GPT 模型目录的账号冒充 GLM 渠道，或在无有效凭据时启用 disabled GLM 平台。
