# 项目概览

- 项目：XCode，自托管 AI API 网关与订阅分发平台。
- 产品仓库：`xiaohuihuitop/xcode`；生产分支：`main`；官方同步源：`upstream/main`。
- 产品层：用户、API Key、平台授权、套餐、订阅、余额、倍率、计费、用量和管理 UI。
- Runtime 层：账号调度、OAuth 刷新、协议适配、上游请求、重试、冷却和失败切换；当前由 Sub2API 适配器实现。
- 平台是模型白名单、端点能力和账号池的唯一入口；账号只归属一个平台，不新增账号级模型映射。
- API Key 可授权多个平台、多个套餐和余额；套餐优先扣费，不可用时仅按 Key 授权回退余额。
- 套餐使用订阅倍率快照；余额使用全局余额倍率；两种倍率不叠加。
- `PlatformSchedulingID` 只用于调度/粘连/缓存；正数 `PlatformAssetID` 用于数据库、用量、Ops、风控和 Live 身份。
- 当前重点 Runtime 是 OpenAI Images、Chat Completions、Responses 和 Messages；其他渠道按路线图推进。
- 新请求通过纯 `gatewayruntime.Request`、`HTTPExchange` 和 `UsageSink` 连接适配器；生产执行器不得接收 Gin context 或回调公开 Handler。
- 迁移边界：已发布自定义 migration `192-200` 冻结；官方同步使用 `8000-8999`，ProductCore 使用 `9000-9999`。
- 发布：Tag 从 `v1.0.0` 开始，构建本地 `xcode:latest` 并上传 `xcode_latest.tar`；不发布 GHCR。
- 生产验收默认使用 `gpt-5.6-sol`；`glm-5.2` 仅在已配置且经上游模型目录确认的 GLM 账号上执行真实请求与计费验收。
- 详细架构和接手规则分别见 `docs/ARCHITECTURE.md`、`docs/DEVELOPMENT_GUIDE.md` 和 `docs/HANDOFF.md`。
