### 阻塞与待确认

- GitHub 贡献者统计刷新可能有延迟。
- `glm-5.2` 真实验收仍缺有效上游账号/凭据，作为后续可选项；当前 disabled 平台不应在没有该账号的情况下启用，也不阻塞 GPT 主线。
- `/v1/models` 对仅含通配模型规则的平台返回空目录；请求路由不受影响，但客户端无法自动发现实际可用模型。调整为精确模型规则会改变线上平台配置，需用户确认。
- 上线前仍需处理订单套餐快照、退款幂等等风险，详见 `docs/ROADMAP.md`。
- Codex 平台当前只有账号 15 处于可调度状态，账号 16 未启用调度；单账号情况下 Sub2API 可以做同账号重试和冷却，但无法验证或提供账号间失败切换。
