# Sub2API v0.1.179 Phase 5 Runtime Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 XCode 现有平台和 AI 账号后台补齐 `v0.1.179` Runtime 必需的 OAuth、额度、探测、批量设置和运行状态管理，不复制官方 Group/Channel 产品界面。

**Architecture:** 权威覆盖组为 `F002/F003/F008/F016/F023/F025`，共 51 个唯一 commit。后端只暴露脱敏的 Runtime 配置与事实；前端继续使用 XCode 的 `AccountsView`、`PlatformsView` 和账号组件，新 Provider 在代码可用但默认无平台、无账号、无流量。

**Tech Stack:** Go 1.26.6、Gin admin handlers、Vue 3、TypeScript、Pinia/API client、Vitest、现有 settings/accounts.extra。

---

## 不变量

- 本阶段不新增 schema/migration，不恢复 Channel Monitor 表。
- 凭据只允许写入受保护的 AI 账号配置，响应、日志和审计记录必须脱敏。
- 上游费率是待管理员确认的事实，不能直接覆盖模型广场价格或用户扣费。
- 前端不新增“全部平台”伪选项，不覆盖 ProductCore 平台、套餐、余额、API Key 页面。
