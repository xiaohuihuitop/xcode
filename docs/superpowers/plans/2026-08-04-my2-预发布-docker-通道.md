# My2 预发布 Docker 通道 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `my2.0` 建立不会影响正式 `latest` 的 GHCR 和离线 Docker 预发布通道。

**Architecture:** 以 `my2-v<版本>` Tag 作为隔离触发器，独立工作流在该 Tag 的提交上构建前端和内嵌前端的 Go 二进制。工作流为镜像和离线包使用 `my2` 前缀，并创建 GitHub prerelease，不调用正式发布工作流。

**Tech Stack:** GitHub Actions、pnpm、Go 1.26.5、Docker Buildx、GHCR、softprops/action-gh-release。

---

**Files:**
- Create: `docs/superpowers/specs/2026-08-04-my2-预发布-docker-通道-design.md`
- Create: `docs/memory/决策/2026-08-04-my2-隔离预发布通道.md`

- [x] **Step 1: 固化 Tag、镜像和离线包命名**

记录 `my2-v<版本>`、`my2-latest`、`sub2api_my2_latest.tar`，并明确不覆盖正式 `latest`。

- [x] **Step 2: 记录正式渠道隔离边界**

说明不得触发 `release.yml`、不得发布 Docker Hub 正式标签、不得同步 `VERSION` 到 `main`。

### Task 2: 新增独立 my2 发布工作流

**Files:**
- Create: `.github/workflows/my2-release.yml`

- [x] **Step 1: 写入隔离触发器和发布元数据解析**

```yaml
on:
  push:
    tags:
      - 'my2-v*'
```

工作流必须从 `my2-v<版本>` 解析版本，并拒绝非 `my2-v` 标签。

- [x] **Step 2: 构建前端与内嵌前端的 Go 二进制**

```bash
pnpm install --frozen-lockfile
pnpm run build
go build -C backend -tags=embed -trimpath -o ../.release/my2/sub2api ./cmd/server
```

- [x] **Step 3: 构建并推送带 my2 前缀的 amd64 镜像**

```bash
docker buildx build --platform linux/amd64 --load \
  -t "sub2api:my2-latest" \
  -t "sub2api:my2-${VERSION}" \
  -t "${IMAGE}:my2-latest" \
  -t "${IMAGE}:my2-${VERSION}" \
  .release/my2
```

- [x] **Step 4: 生成离线包并创建 prerelease**

```bash
docker save "sub2api:my2-latest" "sub2api:my2-${VERSION}" | gzip -9 > sub2api_my2_latest.tar
sha256sum sub2api_my2_latest.tar > sub2api_my2_latest.tar.sha256
```

将两个文件附加到 Tag 对应的 GitHub prerelease。

### Task 3: 静态验证与发布

**Files:**

- [x] **Step 2: 验证 YAML 和正式发布边界**

- [x] **Step 3: 提交并推送首个测试 Tag**

```bash

git push origin my2.0
git push origin my2-v0.2.0
```

Expected: GitHub Actions 的 `My2 Preview Release` 工作流开始执行；正式 `Release` 工作流不触发。

结果：`my2.0` 已推送，`my2-v0.2.0` 对应的 `My2 Preview Release` 成功完成。Release 附带 `sub2api_my2_latest.tar` 与 SHA256；下载后已确认其仅包含 `sub2api:my2-latest` 和 `sub2api:my2-0.2.0`。
