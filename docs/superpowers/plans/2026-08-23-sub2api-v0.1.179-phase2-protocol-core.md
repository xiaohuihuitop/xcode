# Sub2API v0.1.179 Phase 2 Protocol Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同步 `v0.1.179` 的 OpenAI Chat/Responses/Messages 和通用协议核心，同时保持 RuntimeBridge v1、ProductCore 和生产路由行为不变。

**Architecture:** 以功能矩阵 `F019`、`F022` 的 47 个唯一 commit 为权威实现集合，`R002-R005` 仅作 Release 验收交叉索引。纯协议算法放在 `internal/runtime/sub2api` 或 `internal/pkg/apicompat`，Handler 只把纯 `v1.Request` 和 `HTTPExchange` 接到 Driver；不得把 Gin、Ent 或扣费逻辑放入 Runtime。

**Tech Stack:** Go 1.26.6、RuntimeBridge v1、HTTP/SSE/WebSocket、标准库 JSON、现有 Go 单元测试。
