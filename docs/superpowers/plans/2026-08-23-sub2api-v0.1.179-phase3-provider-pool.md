# Sub2API v0.1.179 Phase 3 Provider Pool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同步 `v0.1.179` 的 AI 账号池、OpenAI/Codex、Grok、Gemini/Antigravity、Kimi、GLM、DeepSeek 和代理探测能力，且所有新 Provider 默认未配置、未启用。

**Architecture:** 权威覆盖组为 `F001/F004/F007/F010/F012/F018/F024`，共 100 个唯一 commit。Runtime 管理 AI 账号凭据、额度、调度、冷却和失败切换；ProductCore 用户账号、平台授权、套餐和余额不进入本阶段。Provider 差异通过 `OpenAIRuntimePort` 和新增的纯 Runtime provider 配置映射集中到 Driver。

**Tech Stack:** Go 1.26.6、RuntimeBridge v1、OAuth/API Key、`accounts.extra` JSON、现有调度和代理服务。

---

## 不变量

- 不新增 Provider 平台记录，不自动启用账号，不改变现有平台选择。
- 默认 0 个 migration；Codex fingerprint 和 quota snapshot 使用 `accounts.extra` 的 lazy/CAS 更新。
- 不恢复 Group、Channel、user-provider quota 或第二套账号表。
- 任何 schema、公共 contract、依赖或根配置变化都必须停止并单独确认。
