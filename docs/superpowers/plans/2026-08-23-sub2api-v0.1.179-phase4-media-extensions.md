# Sub2API v0.1.179 Phase 4 Media Extensions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同步 `v0.1.179` 的 Composite、图片、视频、音频、Realtime、Live、Search 和扩展端点，并确保异步成功/失败终态与 ProductCore 扣费严格分离。

**Architecture:** 权威覆盖组为 `F005/F006/F011/F013/F014/F017/F026`，共 33 个唯一 commit；`R001/R006` 是交叉验收索引。Runtime 管理 Provider 任务状态并通过现有 `v1.UsageFacts` 上报事实，ProductCore 只对唯一成功终态计价。

**Tech Stack:** Go 1.26.6、RuntimeBridge v1、HTTP/SSE/WebSocket、现有 media/auxiliary executor 和 UsageSink。

---

## 不变量

- 不恢复 `composite_model_routes`、Group、Channel 或媒体价格表。
- Composite 优先使用现有 `settings` JSON；本阶段不新增 migration。
- 不扩展 RuntimeBridge v1；现有 Endpoint/InboundEndpoint 无法表达时停止并评审 contract。
- 客户端取消、Provider 失败和超时不得产生成功 usage 或扣费。
