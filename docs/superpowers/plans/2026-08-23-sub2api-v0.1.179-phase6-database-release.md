# Sub2API v0.1.179 Phase 6 Database And Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 `v0.1.179` 的 ProductCore 映射、数据库条件评审、全量自动化和一次性环境验收，并在用户另行确认前停在发布边界。

**Architecture:** 权威覆盖组为 `F009/F015/F020/F021/F027`，共 48 个唯一 commit，`R007` 是价格交叉验收索引。官方价格、Group、Channel 和 subscription 变化只映射到 XCode ProductCore；默认数据库变化为 0，只有已记录的查询/完整性证据才能提出独立 migration 评审。

**Tech Stack:** Go 1.26.6、PostgreSQL、Vue/pnpm、Docker 离线包、XCode ProductCore、现有 CI/Release 门禁。

---

## 不变量

- 不执行官方 migration `217-228`，不复用编号，不修改已发布 migration checksum。
- Runtime migration 仅允许 `8000-8999`，ProductCore 仅允许 `9001-9999`；任何新 migration 在写文件前再次请求确认。
- Runtime 不直接写用户余额、套餐用量或最终价格。
- 推送、Tag、Release、离线包上传和香港升级是本计划之外的外部动作，必须另行确认。
