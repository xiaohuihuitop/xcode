> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Synchronize the confirmed P0 F001 OpenAI/Codex Runtime behavior from official Sub2API `v0.2.0` into XCode while preserving ProductCore, RuntimeBridge, schema, dependency, release, and deployment ownership boundaries.

**Architecture:** Port handler-owned compatibility behavior as narrow XCode adapter code and copy only the approved F001 `apicompat` rows into the Official Runtime zone through a verified group projection. Keep the canonical full `sync-plan.json` immutable, use target baselines and backups around the non-transactional apply, and prove each behavior with a red-green regression cycle.

**Tech Stack:** Go 1.26.6, Gin, `tidwall/gjson`, `coder/websocket`, Python synchronization validators, PowerShell structured JSON projection.

- [x] **Step 3: Add and connect the narrow classification helper**

Implement the reviewed helper:

```go
func openAIWSIngressEndedByClient(err error) bool {
	if err == nil {
		return true
	}
	var closeErr *service.OpenAIWSClientCloseError
	if errors.As(err, &closeErr) && closeErr.StatusCode() == coderws.StatusNormalClosure {
		return true
	}
	if coderws.CloseStatus(err) == coderws.StatusNormalClosure {
		return true
	}
	return errors.Is(err, context.Canceled)
}
```

Use it at the WebSocket ingress cleanup branch so only non-client endings reach `shouldReportOpenAIWSProxyAccountFailure`, account health observation, and scheduler failure reporting. Preserve unsupported-model-switch behavior and all abnormal upstream error attribution.
